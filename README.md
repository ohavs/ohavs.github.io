# ohavs.github.io

The public site of the Currency Converter + Widget app (https://ohavs.github.io):

- `privacy.html`: the privacy policy Google Play and the app link to.
- `app-ads.txt`: authorizes AdMob to sell the app's ads (read by ad buyers from the developer website's root).
- `Currency-26/`: redirects from the policy's old address, which builds up to 5.0.25 link to.
